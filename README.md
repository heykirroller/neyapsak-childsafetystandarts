# Child Safety Standards

NeYapsak is designed to be safe for all users, including children.

## Data Collection
This app does NOT:
- Collect personal data
- Require account creation
- Use social features
- Allow user-generated content
- Track users
- Access contacts, camera, or location

## Inappropriate Content
The app does not contain:
- Violence
- Sexual content
- Hate speech
- User communication features
